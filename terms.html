Requirements and limits

Use a normal local folder. Python with Tkinter must already be installed or installed separately from python.org. No Mac/Linux GUI support or signed executable is included. No administrator access is needed for ordinary accessible folders.

Scans stop at 250,000 files. Links, junctions/reparse points, cloud placeholders, nonordinary files and repeated hard links are skipped. Permission errors, file changes and cancellation can produce partial results. The GUI lists the 5,000 largest files and HTML reports list the first 500; CSV/JSON include all scanned file rows. JSON includes duplicate groups and diagnostic details.

Sizes are logical file sizes, not guaranteed recoverable disk space. Matching copies can be required by programs, backups or projects. Keep an original, review the context and recheck files before taking action. The tool does not automatically delete files, repair disks, recover lost data, remove malware or guarantee a faster computer.
